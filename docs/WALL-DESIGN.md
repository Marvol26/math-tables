# בונים קיר 🧱 — "build the wall" game mode (Tetris option B; Marat 2026-08-29)

Replaces V2-DESIGN §4 (Rectangle Tetris, whose row-clearing gate failed structurally — §4.6). Same idea, no scoring mechanic: the fact `a×b` is a rectangle **a wide, b tall** (as asked) that the child places in a well; the well simply fills up. A full wall is a celebration and a fresh wall — never a penalty. Coins come from the facts only, exactly as in balloons.

## 1. Rules
- **Mode** `"wall"` (`active.mode`, `session.mode`, `attempt.mode`). Home button `T.home.wallBtn = "בונים קיר 🧱"`, resume `T.home.resumeWallCta = "ממשיכות! 🧱"`. Parent toggle `T.parent.wallEnableLabel = "בונים קיר 🧱 — מצב נוסף"`, `settings.wall = { enabled:false, durationSec:10, options:4 }` (bounds as falling; labels `T.parent.wallDurationLabel` / `wallOptionsLabel` carry the same Hebrew as the falling ones).
- **Well** `CONFIG.WALL = { COLS:10, ROWS:14, DEFAULT_DURATION_SEC:10, MIN/MAX_DURATION_SEC as falling, DEFAULT_OPTIONS:4, MIN/MAX_OPTIONS as falling }`. Cell values: 0 empty, 1 first-attempt correct (coloured by lane palette), 2 wrong (grey), 3 retry (light).
- **Round** = the same plan as every mode (mirror pairs included). On paint: piece `w=a, h=b`, `x` centred, `deadline = shownAt + durationSec·1000`, one journal save. The child taps a well column (piece's left edge moves there, clamped) or ◀ ▶ / arrow keys — **UI-local**, persisted only with the answer. She answers by tapping one of N static option bubbles above the well (`Falling.candidates`, keys 1–N). The answer event carries `x`; `SessionCore.submit` runs the pure reducer inside the same save: landing row (rigid drop) → **if it does not fit: wall complete → `wallsBuilt++`, fresh grid, recompute landing** → place. Correct before `deadline` ⇒ ×2 (`withinLimit` exactly as falling); after the deadline the piece visually rests at the bottom (`landed`), still answerable, no ×2. Wrong ⇒ picture + הבנתי as everywhere, the piece is placed grey; the fact is re-asked at the end (retry, cell 3, 0 coins).
- **Wall complete** toast `T.wall.full = "הקיר התמלא! בונות קיר חדש 🧱🎉"` + confetti (decoration only). Summary line `T.summary.wallsBuilt(n) = "קירות שבנית: " + bdi(n) + " 🧱"` when n ≥ 1; title suffix 🧱; parent history 🧱; per-mode chart line `T.parent.modeNames.wall = "קיר 🧱"` (replaces the placeholder `tetris` key everywhere in `Stats.trends`/charts).
- **Learning effect** as balloons: counts for mastery/map (recognition tap), carryover off. No new ledger ids. Economy identical to balloons (the simulator's wall profile must match its falling numbers).
- **State** `active.wall = { grid, x, wallsBuilt }` in the journal; resume defers the current question (F10) and keeps the grid; a deferred piece re-centres.
- **Parking for three modes** — exactly V2-DESIGN §4.4 with `tetris` → `wall`: `SCHEMA_VERSION` 3, `state.parkedSessions` array (max 2, unique modes ≠ active, LIFO unpark), migration 2→3, `validateImport` for schema ≤ 3 with the journal contract (`wall.grid` = ROWS arrays of COLS cells ∈ {0,1,2,3}, `0 ≤ x ≤ COLS−w`, `1 ≤ w,h ≤ 10`, `wallsBuilt ≥ 0`, settings bounds); every `state.parked` call site moved.
- **Rendering** CSS grid `ROWS×COLS`, cell `min(7vw, 26px)`; the piece is one absolutely positioned div (`--w/--h`) whose `top` transitions over `durationSec`; `transitionend` toggles the visual `landed` class only (the deadline in core is the truth); reduced motion = stationary piece + numeric countdown, moved to the landed position at the deadline; landscape: well beside the card, spectators strip hidden as in falling; the exit button and the landed label follow the falling screen's layout rules (bottom padding, no overlap — measured at 320×568, 375×667, 390×844, 844×390).
- **Ships disabled by default**; NEXT-ACTIONS keeps the playtest item.

## 2. Pure core (`Wall` section in core.js, tested)
`emptyGrid(rows, cols)`, `landingRow(grid, x, w, h)` (top row index of the resting piece or −1 if it cannot fit), `place(grid, x, y, w, h, cell)`, `step(wallState, { x, cell })` → `{ grid, x, wallsBuilt, reset:boolean, y }` implementing the order above. The executor may consult `git show tetris-wip:core.js` (the parked Tetris core) for `landingRow/place/overflows`, renamed and stripped of row clearing.
